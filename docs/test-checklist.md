# 기능 테스트 체크리스트

배포 전 아래 항목을 확인한다. (자동화 도구 없이 수동 점검 가능하도록 구성)

## 핵심 흐름

- [ ] 도서관에서 동화 카드 30개가 표지·제목·출처·읽기 시간·태그와 함께 보인다
- [ ] 검색어 입력 시 제목/주제/작가로 필터링된다
- [ ] 주제·지역·연령·길이 필터가 각각 동작하고 해제된다
- [ ] '아무 동화나 열기'가 임의 동화로 이동한다
- [ ] 동화 상세: 소개/등장인물/장면/출처 탭이 모두 렌더링된다
- [ ] 장면마다 발단~결말(프라이타크) 배지가 표시된다
- [ ] '다시 쓰기' → 방식 선택(줄거리/장면별) → 프로젝트 생성이 된다
- [ ] 줄거리 모드: 15개 요소 각각 원작 그대로/추천/직접 입력/아이디어 도움이 동작한다
- [ ] 인물 바꾸기: 항목 수정 시 카드에 바뀐 설정이 표시되고, 되돌리기가 동작한다
- [ ] 줄거리 4단계: 제목 후보 3개 제안, 6단계 칸 입력, 문장 시작 카드 삽입이 동작한다
- [ ] 장면 모드: 장면 목록 이동, 원작 비교, 연결 문장 추천, 빈 칸=원작 유지가 동작한다
- [ ] 완성 화면: 작가의 말, 이야기 점검, 동화책 미리 보기가 보인다
- [ ] JSON 내보내기 → '내가 쓴 이야기'에서 불러오기가 된다 (잘못된 파일은 친절한 오류)
- [ ] 인쇄 미리 보기에서 헤더/버튼이 숨고 동화책만 나온다 (PDF 저장 적합)
- [ ] 글 전체 복사가 동작한다

## 데이터 보존

- [ ] 입력 중 새로고침해도 작성 내용이 유지된다 (즉시 자동 저장)
- [ ] 단계 이동(3↔4↔5) 후에도 내용이 유지된다
- [ ] 프로젝트 삭제는 2단계 확인 후에만 실행된다

## 접근성

- [ ] Tab 키만으로 모든 버튼·입력·링크 도달, 포커스 링 표시
- [ ] 필터·탭에 aria-pressed/aria-selected가 반영된다
- [ ] 색상 외에 체크 표시·텍스트로도 상태를 구분한다
- [ ] 모바일(360px)에서 가로 스크롤 없이 사용 가능, 터치 영역 44px 이상
- [ ] prefers-reduced-motion 설정 시 애니메이션이 사라진다

## AI/도우미

- [ ] 프록시 미설정 시 모든 도움 기능이 내장 규칙으로 동작한다
- [ ] 아이디어는 항상 3개 제안되고, 선택한 것만 입력된다
- [ ] 생성 중 버튼이 비활성화되어 반복 클릭이 방지된다
- [ ] 잘못된 프록시 주소 입력 시 내장 도우미로 자동 대체된다 (어린이 글 손실 없음)
- [ ] 빌드 결과물(dist/)에 API 키 문자열이 없다

## GitHub Pages 배포

- [ ] `npm run build`가 오류 없이 통과한다 (`tsc -b` 포함)
- [ ] `npm run lint`가 통과한다
- [ ] 배포 후 `https://<아이디>.github.io/newstory/` 첫 화면이 뜬다
- [ ] 하위 경로에서 CSS/JS/폰트가 모두 로드된다 (개발자 도구 404 없음)
- [ ] `#/story/...` 화면에서 새로고침해도 404가 나지 않는다
- [ ] 저장소 이름 변경 시 워크플로의 VITE_BASE 자동 주입으로 정상 동작한다
