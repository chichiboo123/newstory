# 동화 자료 저작권 검토 문서

마지막 검토: 2026-07-15

## 검토 원칙

1. **원전의 퍼블릭 도메인 여부 확인** — 저자 사후 70년(대부분 국가 기준)을 보수적으로 적용. 작자 미상 구전 설화는 채록·전승 시기를 확인.
2. **현대 번역문·각색문 미사용** — 특정 번역가·출판사의 문장은 저작권 보호 대상이므로, 원전의 **사실관계(등장인물, 사건 순서, 결말)만 참고**해 전부 자체 요약으로 새로 작성.
3. **현대 콘텐츠의 고유 설정 배제** — 디즈니 등 영화·애니메이션이 추가한 캐릭터 이름, 노래, 디자인, 결말 변경은 사용하지 않음. 각 작품의 `modernAdaptationCaution`에 구체적으로 명시.
4. **표지·삽화** — 기존 책 표지와 삽화를 사용하지 않고, 이모지 + 그라디언트 조합의 자체 썸네일만 사용.
5. **불확실하면 제외** — 저작권 상태가 불확실한 작품은 포함하지 않음. "오래된 이야기"라는 이유만으로 안전하다고 판단하지 않음.
6. **어린이 발달 수준에 따른 완화** — 잔혹한 원전 장면은 완화하되 핵심 의미를 유지하고, 완화 사실을 `publicDomainNote`에 기록.

## 작품별 기록 항목

각 작품 JSON의 `sourceInfo`에 다음을 기록한다: 원작 출처(`origin`), 퍼블릭 도메인 검토 메모(`publicDomainNote`), 주의해야 할 현대 각색 요소(`modernAdaptationCaution`), 검토 상태(`reviewStatus`), 마지막 검토 날짜(`lastReviewed`).
